# Кейс по продуктовой аналитике: A/B-тестирование новой формы оплаты ЖКХ

Решение кейса для отбора в команду продуктовой аналитики (Т-Банк).

## Описание проекта
Анализ результатов A/B-эксперимента по внедрению автозаполнения реквизитов квитанции в форме оплаты жилищно-коммунальных услуг (ЖКХ).

## Структура решения
- **[Решение_кейса_продуктовая_аналитика_Кусик_А.Д.ipynb](Решение_кейса_продуктовая_аналитика_Кусик_А.Д.ipynb)** — Jupyter Notebook с полным циклом анализа:
  1. Первичный аудит и очистка данных (EDA)
  2. Проверка качества сплитования и SRM-тест
  3. Расчет воронки (на уровне сессий и пользователей)
  4. Статистическая проверка гипотезы (двухвыборочный Z-критерий, доверительный интервал)
  5. Сегментный анализ (ОС, города, возраст)
  6. Анализ длительности прохождения воронки (тест Манна-Уитни)
  7. Продуктовые выводы и рекомендации

## Ключевые результаты
- Конверсия уникальных пользователей выросла с **65.60%** (контроль A) до **80.40%** (тест B).
- Абсолютный прирост: **+14.80 п.п.**, относительный прирост (lift): **+22.56%**.
- Статистическая значимость: **Z = 6.456, p-value = 1.08e-10** (95% ДИ: [+10.37 п.п. ; +19.23 п.п.]).
- Рекомендация: **Раскатка новой формы с автозаполнением на 100% пользователей**.
